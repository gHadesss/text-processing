Описание:
Для каждого трека перебирается количество строчек возможного припева:
1. Все слова текста нормализуются, бэк-вокал в скобках удаляется для более удобного сравнения строк.
2. Соседние n строк последовательно сравниваются по метрике Левенштейна со всеми остальными последовательными частями текста песни и для каждого такого фрагмента строится вектор
   расстояний, поделенных на максимум от длины сравниваемых фрагментов.
3. Для текущего значения n перебираемой длины припева строится матрица из векторов, описанных выше, размерностью N * N, где N = len(track) - n + 1
4. Во всех матрицах ищется строка с наибольшим количеством расстояний, меньших порога, который был подобран на примере входных данных. Индекс найденной строки - номер строки, с
   которой начинается первый припев, все расстояния меньше порога соответствуют остальным припевам. Если таких матриц несколько, выбирается наибольший размер припева.
